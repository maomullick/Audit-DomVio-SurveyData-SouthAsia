# Profile-Based Auditing of Domestic Violence Survey Selection Across South Asia

Code and reproducibility materials for the paper:

> **Profile-Based Auditing of Domestic Violence Survey Selection Across South Asia**

## Overview

This repository contains the end-to-end analysis for auditing differential selection into the Domestic Violence (DV) module of the Demographic and Health Surveys (DHS) across South Asia.

Using DHS Individual Recode data for 796,374 women aged 15–49 across Afghanistan, India, Myanmar, Nepal, and Pakistan, the analysis:

- harmonizes 61 numeric and 8 categorical features;
- reduces the profile space with PCA;
- identifies six interpretable population profiles;
- evaluates 22 machine-learning models under primary-sampling-unit-aware holdout validation;
- performs nested feature-block analysis for design, country, woman-level, household, agency, normative, and interaction variables;
- examines country-specific heterogeneity and leave-one-country-out transferability.

The best pooled model, HistGradientBoosting, achieves ROC-AUC 0.9167 and PR-AUC 0.9612, compared with 0.8475 and 0.9203 for a design-only baseline.

## Data availability

**DHS microdata are not included in this repository.** DHS Individual Recode data are restricted and must be requested from The DHS Program:

https://dhsprogram.com/data/

To reproduce the analysis:

1. Obtain the DHS Individual Recode datasets for Afghanistan, India, Myanmar, Nepal, and Pakistan.
2. Place the raw data files in a local directory such as `data/raw/`.
3. Open the notebook and update the `DATA_DIR` variable in the first configuration cell.
4. Run all cells.

Do **not** commit DHS microdata, derived individual-level records, or any restricted data to GitHub.

## Notebook pipeline

The single notebook `dv_selection_audit_south_asia.ipynb` covers:

1. Data loading and harmonization across five South Asian countries.
2. Feature construction: 61 numeric and 8 categorical variables.
3. PCA-based profile reduction and identification of six profiles.
4. PSU-aware training/test partition.
5. Model zoo evaluation across 22 learners, including:
   - majority-class and stratified-random baselines;
   - design-only baseline;
   - logistic regression, linear SVM, LDA, naive Bayes;
   - decision trees, random forest, extra trees;
   - AdaBoost, gradient boosting, HistGradientBoosting;
   - KNN, RBF SVM;
   - PCA-based pipelines;
   - XGBoost and LightGBM.
6. Nested feature-block analysis:
   - design;
   - country;
   - woman-level demographics;
   - household;
   - agency and norms;
   - explicit interactions.
7. Country-specific and leave-one-country-out analyses.
8. Figure and table generation for the paper.

## Key results

| Model / specification | ROC-AUC | PR-AUC |
|---|---:|---:|
| Design-only baseline | 0.8475 | 0.9203 |
| HistGradientBoosting | **0.9167** | **0.9612** |

Main findings:

- Woman-level characteristics provide the largest incremental predictive gain.
- Household, agency, normative, and explicit interaction blocks add little out-of-sample performance.
- Country-specific analyses show substantial heterogeneity.
- Leave-one-country-out evaluation indicates limited transferability of the incremental profile signal.

## Reproducibility notes

- Random seeds are set in the notebook.
- Model evaluation uses PSU-aware holdout validation.
- The same held-out PSUs are used across model comparisons.
- Figures and tables may be regenerated by running the notebook.
- Large intermediate files and restricted DHS data should be excluded via `.gitignore`.
